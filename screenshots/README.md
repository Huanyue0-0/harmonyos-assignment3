## 2. 拍摄方式

- **设备自带截屏**：电源键 + 音量下（或三指下滑），再导回本机；
- **命令行（需连接设备）**：
  ```bash
  export DEVECO_HOME=/Applications/DevEco-Studio.app/Contents
  devecocli ui screenshot --path ./screenshots/01_main_portrait.png
  ```
- 横屏截图前先旋转设备（或 `devecocli ui` 无旋转能力时用模拟器旋转按钮）。
